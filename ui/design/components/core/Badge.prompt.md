Small rounded tag for status, category, or ids. Pill-shaped, role-colored soft background.

```jsx
<Badge tone="violet">مستند</Badge>
<Badge tone="warn">زیرفرآیند</Badge>
<Badge tone="mono" mono>cooking-001</Badge>
```

Tones: `violet`, `warn` (sub-process), `danger`, `ok`, `neutral`. `mono` switches to the LTR monospace id style.
