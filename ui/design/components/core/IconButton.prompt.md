Square icon-only button for toolbars and row actions (e.g. delete, undo, zoom). Holds one 16–18px line-SVG.

```jsx
<IconButton tone="danger" title="حذف فرآیند">{trashSvg}</IconButton>
```

Tones: `neutral` (white/violet border), `violet` (soft violet), `danger` (soft red). Default 38px square, `var(--radius-control-lg)`.
