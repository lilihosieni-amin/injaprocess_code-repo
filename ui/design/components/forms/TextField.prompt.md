Labelled text input. Violet-tinted border that focuses to coral; optional leading icon and helper hint.

```jsx
<TextField label="نام فرآیند" placeholder="مثلاً پخت غذای روز" />
<TextField icon={searchSvg} placeholder="جست‌وجوی نام یا شناسه…" />
```

Pass `dir="ltr"` for latin ids. Use the `icon` prop for a search-style field.
